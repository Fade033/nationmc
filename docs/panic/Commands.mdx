# Commands
<span className="panic-badge">Protected by Panic!</span>

Panic! has two commands for players. Everything else under `/panic` is reserved for staff and is not listed here.

| Command | Who can use it | What it does |
| --- | --- | --- |
| `/report <player> [reason]` | Every player | Reports an online player for suspected cheating. The reason is optional; Tab suggests common reasons. See [Reports & Fair Play](./reports). |
| `/panic leave` | Every player | Leaves the server voluntarily while other players are waiting in the queue. Grants queue priority for your next join and, under certain conditions, a small trust bonus. See [Queue System](./queue). |

*Notation: `<player>` is required, `[reason]` is optional. Type commands in the chat window.*

:::note[Good to know]
Both commands only work while you are online. If the queue removed you from the server, simply reconnect; no command is needed for that.
:::
