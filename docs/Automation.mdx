Tired of manual grinding and endless mining? We use the premium version of **Minetorio** to bring deep, satisfying automation to the server. Build massive factories, set up intricate resource processing lines, and automate the creation of literally anything you want. From automated quarries to complex item crafters, let the machines do the work while you focus on empire-building.

To open the main Minetorio menu, open the main menu by typing `/menu` and select the Minetorio icon or type `/minetorio:mt`. To see the full Minetorio guide click [here](https://minetorio.gitbook.io/).
